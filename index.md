## Project Overview

This project proposes a Python-based speech noise reduction system using short-time Fourier transform (STFT), Wiener filtering, and inverse STFT overlap-add reconstruction.

The aim is to reduce additive background noise in speech recordings while preserving speech intelligibility. The project will compare clean, noisy, and enhanced speech using waveform plots, spectrograms, and SNR improvement.

## Planned Tools

- Python
- NumPy
- SciPy
- librosa or soundfile
- matplotlib

## Planned Evaluation

- Input and output SNR comparison
- Spectrogram comparison
- Listening examples
- Discussion of limitations such as musical noise and sensitivity to noise estimation
